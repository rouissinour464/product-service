
# Product Service  (Spring Boot 3.3, Java 17)

Microservice de gestion des produits cosmétiques (CRUD + recherche) avec UI Thymeleaf moderne, Swagger, Docker multi-stage & Compose.


## Docker Compose (Postgres 5433, App 8081)
```
docker compose up --build
```
- UI : http://localhost:8081/
- Swagger : http://localhost:8081/swagger-ui.html
